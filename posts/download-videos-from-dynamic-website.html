如何从动态网站下载视频：一次实战记录

2026 年 5 月 8 日 15 分钟阅读
摘要：本文记录了从星语智能官网下载应用案例视频的完整过程，包括遇到的技术挑战、解决方案和最终实现方法。适用于需要从 React/Vue 等动态网站抓取媒体资源的场景。

📋 任务背景

用户需要从 https://www.xingyu-ai.com/ 网站下载几个应用案例视频。 看似简单的任务，实际上遇到了不少技术挑战。

🚧 遇到的挑战

1. 浏览器工具故障

一开始尝试使用 OpenClaw 的浏览器工具，但遇到超时错误：

browser tool timed out. Restart the OpenClaw gateway.

解决方案：重启 gateway 服务

openclaw gateway restart

但重启后浏览器仍然不可用，需要寻找替代方案。

2. 动态渲染的单页应用

通过 curl 和 web_fetch 获取的 HTML 内容非常有限：

<div id="root"></div>
<script type="module" crossorigin src="/assets/index-Dwpe8heu.js"></script>

问题分析：

  • 网站使用 React + Vite 构建
  • 视频链接通过 JavaScript 动态加载
  • 静态 HTML 中不包含视频资源地址
  • 传统的 curl + grep 方法无法获取视频链接

3. 视频链接隐藏较深

尝试从 JS 文件中提取视频链接：

curl -s https://www.xingyu-ai.com/assets/index-Dwpe8heu.js | grep -oE 'https?://[^"]+\.mp4'

结果：无输出。视频链接被打包在编译后的 JS 代码中，难以直接提取。

✅ 最终解决方案

方案选择：Playwright 自动化浏览器

由于静态抓取不可行，决定使用 Playwright 来渲染完整的页面并捕获网络请求。

步骤 1：安装 Playwright

# 安装 Playwright
cd /tmp
npm install playwright

# 安装 Chromium 浏览器
npx playwright install chromium

步骤 2：编写爬取脚本

创建 download-xingyu.js：

const { chromium } = require('playwright');

(async () => {
  const browser = await chromium.launch({ headless: true });
  const page = await browser.newPage();
  
  // 访问目标网站
  await page.goto('https://www.xingyu-ai.com/', { 
    waitUntil: 'networkidle', 
    timeout: 30000 
  });
  
  // 等待页面完全加载
  await page.waitForTimeout(5000);
  
  // 查找所有 video 元素和 source 元素
  const videos = await page.evaluate(() => {
    const results = [];
    
    // 查找所有 video 标签
    document.querySelectorAll('video').forEach((video, i) => {
      if (video.src) results.push({ type: 'video', src: video.src, index: i });
      video.querySelectorAll('source').forEach(source => {
        if (source.src) results.push({ type: 'source', src: source.src, index: i });
      });
    });
    
    return results;
  });
  
  console.log('Found videos:', JSON.stringify(videos, null, 2));
  
  await browser.close();
})();

🛠️ 技术栈总结

工具 用途 说明
curl 初步探测 获取静态 HTML，判断网站类型
grep 文本搜索 尝试从 HTML/JS 中提取链接
Playwright 页面渲染 执行 JavaScript，获取动态内容
Node.js 脚本运行 执行 Playwright 自动化脚本
curl 文件下载 批量下载视频文件

📝 方法论总结

动态网站爬取的一般流程

  1. 初步探测
    • curl/wget 获取 HTML
    • 检查是否包含目标资源
  2. 判断网站类型
    • 静态网站 → 直接 grep 提取链接
    • 动态网站 (SPA) → 需要浏览器渲染
  3. 选择工具
    • Playwright/Puppeteer → 完整浏览器自动化
    • Selenium → 老牌选择，支持多浏览器
    • jsdom → 轻量级 JS 执行
  4. 提取资源
    • DOM 查询 (querySelectorAll)
    • 网络请求拦截
    • JavaScript 变量提取
  5. 批量下载
    • curl/wget/aria2

关键技巧

  • 等待网络空闲：waitUntil: 'networkidle' 确保所有资源加载完成
  • 额外等待时间：动态内容可能需要额外延迟
  • 多方式提取：同时尝试 DOM 查询和网络请求拦截
  • 错误处理：添加超时和重试机制

⚠️ 注意事项

法律合规

  • 确保爬取行为符合网站 robots.txt 规定
  • 仅下载允许公开访问的资源
  • 尊重版权，不要用于商业用途

技术限制

  • 某些网站使用 CDN 或防盗链机制
  • 视频可能是分片传输 (HLS/m3u8)
  • 可能需要处理 Cookie/认证

性能优化

  • 使用 headless: true 减少资源消耗
  • 合理设置超时时间
  • 批量下载时控制并发

🔧 完整脚本参考

// download-videos.js
const { chromium } = require('playwright');
const { execSync } = require('child_process');
const fs = require('fs');
const path = require('path');

const OUTPUT_DIR = './downloads';

async function downloadVideos() {
  // 创建输出目录
  if (!fs.existsSync(OUTPUT_DIR)) {
    fs.mkdirSync(OUTPUT_DIR, { recursive: true });
  }

  const browser = await chromium.launch({ headless: true });
  const page = await browser.newPage();
  
  try {
    // 访问页面
    await page.goto('https://www.xingyu-ai.com/', { 
      waitUntil: 'networkidle',
      timeout: 30000 
    });
    
    // 等待内容加载
    await page.waitForTimeout(5000);
    
    // 提取视频链接
    const videos = await page.evaluate(() => {
      const results = [];
      document.querySelectorAll('video source, video').forEach(el => {
        const src = el.src || el.getAttribute('src');
        if (src && !results.includes(src)) {
          results.push(src);
        }
      });
      return results;
    });
    
    console.log(`找到 ${videos.length} 个视频`);
    
    // 下载视频
    for (const videoUrl of videos) {
      const filename = path.basename(videoUrl);
      console.log(`下载：${filename}`);
      execSync(`curl -LO "${videoUrl}"`, { 
        cwd: OUTPUT_DIR,
        stdio: 'inherit'
      });
    }
    
  } finally {
    await browser.close();
  }
}

downloadVideos().catch(console.error);
